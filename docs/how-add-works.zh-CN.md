# ADD 工作原理：当前新 V1

更新：2026 年 10 月 8 日。[完整文档](https://add.fun/docs/zh/) · [开发接入](https://add.fun/sdk/zh.html)。

ADD 支持 BSC（56）、Ethereum（1），合约资产按链独立。BSC 毕业到 PancakeSwap V2，ETH 到 Uniswap V2。BSC 新 V1 默认参考 **4 BNB** 为此部署常量；ETH 初始 **1 ETH**，业主可修改后续新建默认值。已创建项目目标不变。

## 库存、买卖、毕业

发行量自填，不再一律 10 亿。实际接入发行币分为募集和加池两个相等整数半份，奇数最小单位余数是多余资产。原生币、USDT、自定义募集币需通过精度和直连包装原生币 V2 路由检查。

```text
固定募集兑换比例 = 已登记募集币目标 / 募集库存
```

比例只对募集币固定，不固定原生换算、美元价值或外盘价。内盘买卖支付/领取 BNB、ETH，必要时兑换募集币，按实际原生结算收 1%。0 转账税不免内盘费。

未售募集库存**严格小于接入总量 1%**时尝试毕业，偶数库存相当于售出募集一半的 98% 以上。用实际储备与预留半份加池，不必凑满参考目标。最后多付款退买家，未售币留 Portal，成功收到 LP 进黑洞，之后内盘关闭。

加池失败保留最后成交、费用和超付退款，暂停内盘并保护储备。任何人可重试原池；业主可尝试报价保护的备用资产换池，失败回滚；也可永久开启按比例交币退款，返原募集资产，历史费用不退，退款不再收费，此后放弃毕业。

## 税款、分红、矿池

买卖税分别创建时固定，整数 0～10，至少一边大于 0，毕业后生效，钱包互转免税。识别 V2 池进出收税，包括手动加撤池；平台自动流动性操作免税。四项分配的是已收税款，合计 100%：

- 营销到指定接收人或绑定矿池。
- 销毁发行币进黑洞，不减少 totalSupply。
- 分红占比大于 0 时创建独立每币账本，原生币/指定币/本币奖励，合格持仓至少 10000 枚，累计权益领取，不是 50 地址轮询。
- 自动加 V2 池，新增 LP 进黑洞。

税币先累计，符合条件后续卖出或公开 processTaxes 处理旧税，受价格、Gas 和门槛约束，不保证每笔即时支付。初始门槛发行量 0.001%，毕业起每 365 天减半，最低一个最小单位；单次上限仍为 0.01%。任何人可替持有人 claimFor 付 Gas，奖励只能给该持有人。

税入矿池使用营销分配，不增加第五项税。工厂绑定本币、LP 或自定义本金，毕业后激活实际交易对/资产再产生负债。质押、领取、checkpoint 识别新税款，中途到账摊入本轮剩余时间；结束后新税款开启相同 1～360 天周期，过去赚到未领的奖励不会清零。

## 质押 V2 与权限

单独矿池可预付奖励、选有限次数减半，或循环注入。本金随时取回/到期/等额分批，每筆质押独立计时；奖励不受本金锁定影响。无人质押暂停奖励有效时间，本金按真实时间继续解锁。按实际到账记账，奖励领取收同奖励币 1% 固定维护费，本金不收平台费。

矿池无业主、不可升级、无救援提币入口，只分指定奖励资产，不自动转发本金附带其他分红。rebase、reflection、发送方额外扣款资产不宣传兼容。

新 V1 Portal 业主管理工厂准入、自定义/外部新接入开关和失败处理，只能取**未受保护多余资产**，不能提募集/退款储备。删除工厂只影响新接入，旧绑定不变；业主交接需接受；不可升级。[权限详情](https://add.fun/docs/zh/permissions/)。

## SDK 与历史边界

SDK 0.2.0 的 AddV1Client 显式选链，支持读取报价、未签名交易/退款/创建、税处理、分红、质押 V2。应用提供节点、授权确认、钱包签名提交、回执重组处理；SDK 不保存私钥、不广播。资料托管、vanity 地址准备、DEX 交易另处理。

AddClient/0.1.0 保留旧 BSC v12/v13，旧币目标和权限以旧合约为准，不能套用新规则。公开源码/字节码核验不等于独立审计。此库只含 SDK、说明与品牌，不含整个平台或私密配置。
